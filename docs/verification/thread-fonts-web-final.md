## 可观察行为

完整主题、子帖、楼层和回复正文显式允许字体。共享阅读器及编辑器默认关闭；主题卡片、搜索、通知、消息、草稿摘要、身份资料弹层及管理内容预览不激活字库。摘要只投影展示，不改写来源正文；消息仍按原纯文本协议展示。分享入口没有另一套富文本正文渲染器，本轮不声称验证了不存在的独立分享页。

合法 clipboard v2 在主题编辑器保留字体及支持格式。动态/评论去掉字体与不支持的样式，保留文字、换行、合法站内传送门，普通外链只留标签。纯文本、外部 HTML/CSS、未知字体粘贴到已有字体范围或插入点时，新文字默认字体，其他支持的格式及邻接文字不变，能够撤销。

正文先显示系统字体并自动后台加载，热缓存不重复下载。缺字、新分片失败安静回退，保留同字体已安装的字形；来源撤回、空地址、不可验证 manifest 仍禁用旧家族。阅读不提供下载、进度、错误或重试操作。
