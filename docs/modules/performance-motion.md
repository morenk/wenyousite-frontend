# 性能与动效接入

Web 沿用 `foundation.lock.json` 固定的已发布 Foundation。CSS 使用 `--motion-fast/standard/slow`（120/180/240ms）与标准／退出曲线；JS 通过 [`motion.ts`](../../src/lib/motion.ts) 读取同一契约。`pnpm design:check` 包含动效门禁，拒绝局部硬编码过渡、`transition-all`、宽度进度动画和未处理减少动画的强制平滑滚动。等待超时、toast 生存期和 Embla 物理参数不是过渡毫秒，不混用 Token。

## 共用入口与页面覆盖

| 入口 | 适用页面 | 当前行为与验证 |
| --- | --- | --- |
| Button、Input、Textarea、Tabs、Select、交互开关 | 登录注册、主题、动态、私信、个人页、收藏、工具、站务 | 状态过渡使用快速 Token；提交沿用业务 pending/disabled，失败可重试，不增加成功展示延时 |
| Menu、Popover、Tooltip、Dialog | 全部弹层、编辑器更多菜单、子贴目录、确认框 | 有动效浮层统一标准时长与入场／退出曲线；无动效 Dialog 继续立即展示，保留焦点与键盘状态机 |
| Progress、图片／字体进度 | 正文、头像、背景图、动态等上传与编辑器字体下载 | 可计算进度只用真实数值；轨道定宽、指示器 scaleX，完成立即提交状态；准备与图片处理使用不定进度，不把字节传完当作处理成功 |
| NavigationProgress、Skeleton、LoadingState、列表刷新／分页 | 路由、列表、表单及异步读取 | CSS 持续状态动画在隐藏页暂停；减少动画保留静态状态。快导航沿用短延迟揭示，不假造百分比 |
| 阅读书签条、目标高亮、定位遮罩 | 主题与楼中楼、动态讨论 | JS 与高亮使用共享 Token；仅在目标几何改变时重置稳定窗口，无关 DOM 更新不会延迟揭开；后台暂停测量，用户接管和卸载清理观察器 |
| 工具栏整理、站务折叠 | 个人设置、站务侧栏 | 重排使用快速 Token，清理旧 Web Animation；减少动画禁用重排，折叠沿用明确 height 过渡与全局减少动画规则 |
| 轮播、灯箱、音频控件 | 动态、主题图片、正文音频 | 灯箱使用共享 Token 与实时减少动画偏好；Embla 减少动画时 duration=0；音频局部 CSS 接入 Token。媒体播放与自动暂停仍由既有控制器负责 |
| 字体、图片就绪 | 阅读器与 Milkdown | 就绪由实际资源状态决定，不用动画延时掩盖；字体释放与撤回、图片确认与恢复沿用原协议 |

全局减少动画规则原本已覆盖 `animate-spin`，无需给所有页面增加第二套 spinner。没有为页面、列表或正文增加入场动画。`aria-busy`、进度条数值、状态文本和焦点交接不依赖动画是否执行。

## Mobile 反馈的 Web 对照

| Mobile 现象 | Web 代码证据与处理 | 回归入口 |
| --- | --- | --- |
| 私密帖及使用久后变卡 | 未获得同设备复现，不能断言存在相同泄漏；Web 已有五页讨论窗口、可见字体租约与有界驻留。本次移除全站编辑刷新和无关 DOM 对稳定窗口的干扰 | `use-update-post`、`discussion-target-reveal`、`dynamic-text-font-runtime`、`visible-font-demands` |
| 编辑正文发布后需多次刷新 | 原先丢弃 PATCH 正文并等待所有楼层／回复刷新。现在取消对应旧读取，以规范正文、版本和编辑时间回填已有窗口、置顶、内嵌回复、默认／子贴正文和详情，保留分页、计数与上下文；不合成未授权详情 | `use-update-post.test.tsx`、`use-thread-write-aggregate.test.tsx`：迟到读取、筛选窗口、跨会话、冲突／权限错误；新回归在旧实现失败 |
| 非首次进入仍等待字体 | v2 新 owner 原先在驻留复用前等待策略请求。已校验清单及全部所需字形仍驻留时先获得租约并显示，后台继续策略收紧与撤回检查；缺字、未驻留与冷加载仍走完整检查 | `dynamic-text-font-runtime.test.ts`：元数据挂起时复用、无新增下载、释放归零；旧实现失败 |
| 重新编辑卡在读取正文 | Web 编辑直接使用当前楼层正文和 version，未发现重复读取正文请求；缓存回填使再次打开读取新版本。Milkdown 仍按需单实例挂载 | `floor-card`、`reply-list`、`thread-composer` 组件回归 |
| 新发／编辑后定位卡数秒 | Web 内联发表成功关闭编辑器，不强制新建定位流程；取消等待后台列表／统计刷新。显式跳转只在几何改变时延长稳定等待；滚动目标向上取整，防止上一条以小数像素越过阅读线、干扰返回位置 | `use-create-post.test.tsx` 的永不完成刷新；`discussion-target-reveal.test.ts` 的持续无关 DOM 更新与小数高度；旧实现均失败。浏览器检查万条窗口与编辑后返回 |
| 图片上传转圈约十秒 | 未发现固定十秒等待或每次重复编码；同 File 已复用规范化与摘要；重选同内容的已完成／处理中预约现先续查，只有确需直传才解码编码。准备反馈提前到容器检查／解码前，服务端处理保持不定进度。仍需实际图片大小与网络阶段证据才能归因 | `upload-image.test.ts` 保留 GIF、格式／元数据、大小、取消、确认、轮询与恢复；`image-upload-progress.test.tsx` |
| 定位结束进度动画卡顿 | Progress 原先逐帧 width 过渡；改用 transform。不能仅据截图宣称所有设备流畅 | `progress.test.tsx`、`motion-performance.spec.ts` 的实际候选 CSS、布局计数与帧间隔 |

保存只更新当前访问者已有阅读数据；退出再登录同账号也视为旧会话，普通 token 刷新不误取消。较低版本结果不会覆盖更高版本。编辑不改变窗口成员与统计，标记过期供下次读取复核；新建仍以服务端刷新结果决定筛选、排序、分页和计数，不把新楼层硬插到任意窗口。跨页权限重新核验规则不变。

## 验收与测量边界

单元和组件测试覆盖即时成功、慢刷新、失败保留、重试／取消、版本冲突、会话切换、隐藏恢复、资源释放和减少动画。浏览器必须使用[隔离 E2E 入口](../rich-text-real-api-acceptance.md)，不能在真实环境自动登录、上传或发帖。

`e2e/motion-performance.spec.ts` 在实际候选 CSS 下渲染共用 Progress 的合成内容，保留亮色／黑夜及 1024/1440px 截图，在 Chromium 比较 width 与 transform 更新的 LayoutCount、记录逐帧间隔。它只证明该场景的布局成本变化，不能代表用户原设备、复杂私密帖、网络或服务端处理时间。正式检查结果、runId、资源清理、源码 SHA 与负责人验收状态放在 PR 和任务交付记录中，不把本页当作性能测试结果快照。
