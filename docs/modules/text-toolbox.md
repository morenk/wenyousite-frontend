# 文字工具箱

## 嵌入路由约定

- Web 入口 `/tools`，详情 `/tools/vertical`、`/tools/morse`、`/tools/fancy`、`/tools/names`。
- App 匿名入口 `/tools/embed`，详情 `/tools/embed/vertical`、`/tools/embed/morse`、`/tools/embed/fancy`、`/tools/embed/names`。嵌入入口使用同一工具组件，隐藏网站导航、登录和账户能力，不挂载认证恢复、每日签到、消息订阅等业务初始化，不发起业务 API 请求。
- 嵌入入口接受可选 `theme=light|dark`。有效值优先于浏览器偏好，不写入主题存储；缺省或非法值跟随系统。嵌入页内导航保留有效主题参数，使用同源完整文档导航而非客户端 pushState，以便原生容器核验 URL 和更新标题。App 主题改变后可以重新加载带新参数的 URL；重新加载会清空当前输入和结果。
- 仅使用本站 HTTPS 路由与本站构建资源；不需要原生 JS bridge、登录态注入或用户凭证。工具输入、计算结果仅在页面内存存在，不进入 URL、Storage、日志、分析或业务接口。
- 页面无法加载、连接失败及 HTTP 错误由 WebView 容器显示重试/返回；资源加载或起名词库加载失败由工具页面显示中文错误与重试按钮。未知工具路径显示页面不存在视图，不重定向到登录或第三方页面。Next.js 流式响应可能已发送 HTTP 200，不能只凭状态码判断工具是否存在；Mobile 只生成上述四个已知工具 ID。
- 复制仅由用户明确点击触发：优先 Clipboard API，不可用或被拒绝时尝试受控 DOM 复制；失败后提示长按或选择结果手动复制。输出可选中，原生容器不需要截获复制请求。
- Web 页面和嵌入页面共用纯文本工具模块；新增原生能力需要独立版本约定。本约定不新增 Backend API、数据库、Foundation Token 或共享渲染协议。

## 页面呈现

普通 Web 目录 `/tools` 仅保留“工具箱”标题，工具以图标、名称和箭头组成的紧凑条目展示，桌面多列、窄屏单列；不显示样例块、卡片说明及底部隐私提示。工具详情与 App 嵌入目录继续保留原有说明及操作界面，路由和主题约定不变。

## 首批能力

- 文字竖排：按 Unicode grapheme 排列，每列从上至下，默认从右至左读；可调整每列字数与列间 ASCII 空格数，每个输入换行另起一列，空行留空列，长行按页高续列，并按页宽分页为可复制纯文本。
- 国际摩斯：字母、数字及标准标点编码/解码，字符用空格分隔、单词用 `/` 分隔，保留换行；不支持的字符或码组明确报错，不吞掉中文。
- 花体英文：将 ASCII 英文字母/可用数字转换为 Unicode 粗体、斜体、花体、双线、等宽、全角等字符；不支持字符保留。各设备字体可见效果可能不同。
- 起名：常见人名支持中国、日本、英国、德国、法国、俄国、美国、意大利、西班牙、韩国、巴西，选择国家、性别、固定姓氏和批量数量；使用各国语言原文和适合该国的姓名顺序，不生成虚构音译或出处。中文另提供自编组合词库的古风/幻想角色名，不声称历史来源或名字寓意。

## 接入与验收

Mobile 应锁定本文件的提交版本接入，不依赖未提交源码。Web 发布兼容路由后再发布消费它的 App；旧 App 无需原生升级即可重新加载兼容网页。网页首次加载需要网络，不承诺离线可用。

工具变换测试和浏览器交互使用本地页面，无登录、无业务数据写入。视觉候选覆盖桌面/窄屏以及亮色/黑夜；自动断言不代替负责人视觉验收。

## 词库与许可

姓名数据从固定开发依赖 `@faker-js/faker@10.6.0` 的 person 定义提取，MIT 许可证保留在 `src/lib/tools/name-data/LICENSE.faker.txt`，并以 `public/licenses/faker.txt` 随发布产物分发（站点路径 `/licenses/faker.txt`）。执行 `pnpm tools:names:generate` 可重复生成，`pnpm tools:names:check` 校验内容与依赖完全一致；后者进入 `pnpm check`。运行时按所选国家动态导入单个 JSON，不加载 Faker 模块或请求外部 API。

英国和美国在该版本都回退 Faker 的 `en` 姓名数据，两者共用英语词库；其他九国不允许静默英文回退。保留各语料的男/女/通用姓名列表，同一次抽样的姓和名使用相同性别；固定姓氏按原样使用。首版提供名与姓的简式组合，不生成父称、头衔、完整法律姓名，也不保证代表实际人口频率。批量结果去重、尝试有上限，数量不足时明确提示。

竖排默认页宽 10 列、页高 20 字、列间 2 个 ASCII 空格、从右向左阅读；页宽/页高可设为 1–100，空格数为 0–10，也可改为不超过 20 个 UTF-16 单位的自定义分隔符（默认 ` | `，不接受换行或控制字符）。每列从上向下；输入换行另起一列，首尾空行均保留为空列，长行按页高拆成连续列，Tab 展开为四个空格。每页补齐指定列数和高度，末页右起时空列位于左侧，左起时位于右侧；只在列间插入分隔符，不加外边界分隔符，页间恰好两个换行，不额外添加末尾换行，也不裁去固定字格或分隔符的空格。空输入返回空结果。结果框限制可见高度并在内部滚动；每次生成后按本次阅读顺序水平滚到起点，不修改文字方向或复制内容。中文/emoji 字格按双宽、拉丁字符按单宽补齐，比例字体或特殊字体下无法保证视觉对齐。缺少 Intl.Segmenter 的旧浏览器明确提示升级，不降级拆开 emoji。

竖排输入最多 10,000 个 UTF-16 单位；生成前计算总页格与最终字符串长度，最多 100,000 格、500,000 个 UTF-16 单位，超限明确报错，避免大量空行或长分隔符导致结果膨胀。提供《静夜思》短诗示例，不预填用户输入。

竖排表单在客户端初始化完成前禁用，避免脚本尚未加载时退回原生 GET 提交；本地文件读取期间同样禁用配置和生成操作。

普通 Web 竖排页可打开本地 `.txt`（不区分扩展名大小写），文件最多 64 KiB，严格 UTF-8 解码并接受 UTF-8 BOM，仍受输入长度限制；读取与解码失败保留原输入，取消选择不改变状态，空文件成功清空输入及旧结果。下载为带 UTF-8 BOM 的 `竖排文字.txt`，正文与复制结果一致；文件只经浏览器本地读取或生成，不上传。App 嵌入页不显示文件选择与下载入口，仅保留复制及相同竖排能力，不新增原生桥或文件交互协议。

国际摩斯字符集以 ITU-R M.1677-1 的字母、数字和页面列出的标点为范围；首版不提供 Unicode 扩展码。编码按词规范化空格，保留换行；不支持字符/码组使整次转换失败。花体基于 Unicode Mathematical Alphanumeric Symbols 并补齐 Letterlike Symbols 的例外，保留未转换字符。

字体门禁仍拒绝原有全部字体入口；Faker 意大利姓氏 `Noto` 仅在严格姓名结构、固定生成数据完全匹配的 JSON 或构建 JSON.parse 字面量内部被识别为姓名，片段外声明与资源路径照常检查。
