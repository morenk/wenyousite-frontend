# 文字工具箱

## 嵌入路由约定

- Web 入口 `/tools`，详情 `/tools/vertical`、`/tools/morse`、`/tools/fancy`、`/tools/names`。
- App 匿名入口 `/tools/embed`，详情 `/tools/embed/vertical`、`/tools/embed/morse`、`/tools/embed/fancy`、`/tools/embed/names`。嵌入入口使用同一工具组件，隐藏网站导航、登录和账户能力，不挂载认证恢复、每日签到、消息订阅等业务初始化，不发起业务 API 请求。
- 嵌入入口接受可选 `theme=light|dark`。有效值优先于浏览器偏好，不写入主题存储；缺省或非法值跟随系统。嵌入页内导航保留有效主题参数，使用同源完整文档导航而非客户端 pushState，以便原生容器核验 URL 和更新标题。App 主题改变后可以重新加载带新参数的 URL；重新加载会清空当前输入和结果。
- 仅使用本站 HTTPS 路由与本站构建资源；不需要原生 JS bridge、登录态注入或用户凭证。工具输入、计算结果仅在页面内存存在，不进入 URL、Storage、日志、分析或业务接口。
- 页面无法加载、连接失败及 HTTP 错误由 WebView 容器显示重试/返回；资源加载或起名词库加载失败由工具页面显示中文错误与重试按钮。未知工具路径显示页面不存在视图，不重定向到登录或第三方页面。Next.js 流式响应可能已发送 HTTP 200，不能只凭状态码判断工具是否存在；Mobile 只生成上述四个已知工具 ID。
- 复制成功显示 1.5 秒“已复制”浮层提示，重复复制重新计时，离开结果清理计时；提示不占正文布局。失败提示保留到再次复制或离开结果，不误报成功。复制仅由用户明确点击触发：优先 Clipboard API，不可用或被拒绝时尝试受控 DOM 复制；失败后提示长按或选择结果手动复制。输出可选中，原生容器不需要截获复制请求。
- Web 页面和嵌入页面共用纯文本工具模块；新增原生能力需要独立版本约定。本约定不新增 Backend API、数据库、Foundation Token 或共享渲染协议。

## 页面呈现

Web 与嵌入目录仅显示“工具箱”标题和图标、名称、箭头组成的紧凑条目，桌面两列、窄屏单列，采用无外边框的 StackList 分组、60px 条目和20px内缩分隔线；详情仅显示工具标题与返回导航，不显示宣传副标题、样例卡片说明、隐私页脚或默认结果说明。表单仅保留字段标签、无法由控件推断的格式/限制，以及花体兼容性和俄语姓氏等必要提醒。错误、加载、复制和文件操作反馈按实际状态显示；空 live region 保留在辅助技术树中但不占布局。普通 Web 的灰底统一来自 AppChrome，嵌入页自行承载同等单层底色；普通 Web 与嵌入页均保留 content 宽度（48rem）、functional 标题与 card 圆角；输入配置和结果分别置于无外边框面板；主站面板以 19rem 基础宽度并排、必要时自然换行，内边距 16px、间隔 12px，参数自然成组，嵌入页使用单行返回与标题、16px 面板内边距和单列工作流程，空结果不占位；摩斯/花体结果按内容自适应高度并软换行，长结果在框内滚动，竖排仍保留固定字格和横向阅读起点；输入控件为16px文字，操作目标至少44px。竖排的页宽、页高和阅读方向保持可见，列间设置可展开且显示当前值；摩斯编码/解码直接切换，详细字符规则按需展开；花体选项提供真实Unicode样例。嵌入起名页仅在中国显示中文风格选项，切换外国时沿用常见人名并收起不适用的整行；起名结果可选中文字，支持逐个复制与复制全部。仅在用户明确生成后的结果位于视口外时滚动到结果，不移动焦点，并尊重减少动效偏好。键盘焦点仅在工具范围内采用2px轮廓。仅复用纯布局组件，不引入设置页认证逻辑。路由、主题和处理能力不变。

## 首批能力

- 文字竖排：按 Unicode grapheme 排列，每列从上至下，默认从右至左读；可调整每列字数与列间 ASCII 空格数，每个输入换行另起一列，空行留空列，长行按页高续列，并按页宽分页为可复制纯文本。
- 国际摩斯：字母、数字及标准标点编码/解码，字符用空格分隔、单词用 `/` 分隔，保留换行；不支持的字符或码组明确报错，不吞掉中文。
- 花体字：提供字体、符号字形、文字特效和边框装饰四类，补齐伪草书、伪哥特、故障、气泡伪体、偏旁、诅咒、上下单点和 Zalgo，16 种边饰可用于中文，按分类选择，样式名与真实字符样例分行展示，组合标记有上下留白；保留原七种字体与默认花体。生成、清空和复制沿用纯文本流程，切换分类/样式清除旧结果。映射、缺字回退、emoji/组合重音与多行处理见[花体字数据契约](fancy-data-contract.md)。各设备字形覆盖可能不同。
- 起名：常见人名支持中国、日本、英国、德国、法国、俄国、美国、意大利、西班牙、韩国、巴西，选择国家、性别、固定姓氏和批量数量；使用各国语言原文和适合该国的姓名顺序，每个外国结果同时显示中文参考译名，支持复制中文、原文或双语结果。中文另提供自编组合词库的古风/幻想角色名，不声称历史来源或名字寓意。

## 接入与验收

Mobile 应锁定本文件的提交版本接入，不依赖未提交源码。Web 发布兼容路由后再发布消费它的 App；旧 App 无需原生升级即可重新加载兼容网页。网页首次加载需要网络，不承诺离线可用。

工具变换测试和浏览器交互使用本地页面，无登录、无业务数据写入。视觉候选覆盖桌面/窄屏以及亮色/黑夜；自动断言不代替负责人视觉验收。

## 词库与许可

中国姓名数据从固定开发依赖 `@faker-js/faker@10.6.0` 的 person 定义提取，MIT 许可证保留在 `src/lib/tools/name-data/LICENSE.faker.txt`，并以 `public/licenses/faker.txt` 随发布产物分发（站点路径 `/licenses/faker.txt`）。执行 `pnpm tools:names:generate` 可重复生成，`pnpm tools:names:check` 校验内容与依赖完全一致；后者进入 `pnpm check`。运行时中国按需导入原中文 JSON，外国使用独立编辑的双语词库，不加载 Faker 模块或请求外部 API。外国词库每国 20 男名、20 女名、20 姓氏，俄语另有 20 女姓；词库结构、确定性样例、来源与双端交接见[双语姓名数据契约](name-data-contract.md)。

英国和美国共用英语双语对照；其余国家分别收录，保留原文重音。未知外国固定姓氏才显示“姓氏中文写法”必填输入，已知姓自动匹配，纯汉字姓可原样使用；禁止整条结果仅部分翻译。随机俄语姓氏随所选性别变化，用户固定姓氏原样保留。名字和姓氏使用同一性别池。日韩对照是明确收录的角色姓名参考，不声称唯一汉字身份。普通模式生成简式姓与名，不生成父称、头衔、完整法律姓名，也不保证实际人口频率。批量结果去重、尝试有上限，数量不足时明确提示。

双语数据与中文自编组合以本项目 MIT 许可提供，随 Web 分发 /licenses/wenyou-names.txt；原 Faker 许可继续保留。Mobile 从已提交的 Web SHA 同步静态数据，可实现 Flutter 本地生成；旧版 App 的嵌入页仍保持兼容。

竖排默认页宽 10 列、页高 20 字、列间 2 个 ASCII 空格、从右向左阅读；页宽/页高可设为 1–100，空格数为 0–10，也可改为不超过 20 个 UTF-16 单位的自定义分隔符（默认 ` | `，不接受换行或控制字符）。每列从上向下；输入换行另起一列，首尾空行均保留为空列，长行按页高拆成连续列，Tab 展开为四个空格。每页补齐指定列数和高度，末页右起时空列位于左侧，左起时位于右侧；只在列间插入分隔符，不加外边界分隔符，页间恰好两个换行，不额外添加末尾换行，也不裁去固定字格或分隔符的空格。空输入返回空结果。结果框限制可见高度并在内部滚动；每次生成后按本次阅读顺序水平滚到起点，不修改文字方向或复制内容。中文/emoji 字格按双宽、拉丁字符按单宽补齐，比例字体或特殊字体下无法保证视觉对齐。缺少 Intl.Segmenter 的旧浏览器明确提示升级，不降级拆开 emoji。

竖排输入最多 10,000 个 UTF-16 单位；生成前计算总页格与最终字符串长度，最多 100,000 格、500,000 个 UTF-16 单位，超限明确报错，避免大量空行或长分隔符导致结果膨胀。提供《静夜思》短诗示例，不预填用户输入。

所有工具表单在客户端初始化完成前禁用，避免脚本尚未加载时退回原生 GET 提交；竖排本地文件读取期间同样禁用配置和生成操作。

普通 Web 竖排页可打开本地 `.txt`（不区分扩展名大小写），文件最多 64 KiB，严格 UTF-8 解码并接受 UTF-8 BOM，仍受输入长度限制；读取与解码失败保留原输入，取消选择不改变状态，空文件成功清空输入及旧结果。下载为带 UTF-8 BOM 的 `竖排文字.txt`，正文与复制结果一致；文件只经浏览器本地读取或生成，不上传。App 嵌入页不显示文件选择与下载入口，仅保留复制及相同竖排能力，不新增原生桥或文件交互协议。

国际摩斯字符集以 ITU-R M.1677-1 的字母、数字和页面列出的标点为范围；首版不提供 Unicode 扩展码。编码按词规范化空格，保留换行；不支持字符/码组使整次转换失败。花体基于 Unicode Mathematical Alphanumeric Symbols 并补齐 Letterlike Symbols 的例外；按完整字符处理，未映射字符保留。

字体门禁仍拒绝原有全部字体入口；Faker 意大利姓氏 `Noto` 仅在严格姓名结构、固定生成数据完全匹配的 JSON 或构建 JSON.parse 字面量内部被识别为姓名，片段外声明与资源路径照常检查。

## 按需进阶起名

中国、日本、英国、法国、德国、俄国支持进阶起名，默认折叠且不加载进阶词库。展开即启用进阶，收起恢复普通；仅显示“类型”“风格”和当前风格支持的“姓名结构”，不叠加历史开关、时代下拉或姓氏选择。史实参考与文学创作清楚区分，风格标签包含适用时代与身份；风格选项按起始年、结束年从早到晚排列，同期保留原序，无时期的文学方向置后；只排序展示副本，保留既有默认选择与抽样顺序。六国共 52 个风格，含新增 12 个史实方向与 18 个文学方向，词池或结构有实质差异。

展开和收起保留普通模式的固定姓氏、中文写法与中文风格；收起、切换类型或风格时清空旧结果并重置不兼容条件。切换国家清空固定姓氏及中文写法，普通风格恢复常见人名，关闭进阶并清空结果。异步加载完成不得重新开启已关闭的进阶模式或恢复旧国家结果。未知国家不显示进阶入口。首次加载失败可重试，也可直接收起恢复普通。

史实姓名和家系来自逐项来源支持的事实片段，不承诺全时期、全阶层或人口频率，不把同姓等同贵族资格，也不生成无证爵位或谱系。文学词池为编选与原创组合，可按实际支持的结构加入双名、父称、字或别号，明确不指认历史身份。外国结果始终有完整原文与中文参考译名；俄语姓氏和父称按同一性别的固定形式取用，不运行时造词。每次生成 1–50 个并有限重试去重；数量不足仅显示“已生成 X 个不重复姓名”。

共享格式、来源许可和样例见[进阶姓名数据契约](advanced-name-data-contract.md)。运行 pnpm tools:advanced-names:check 校验词池、结构、来源和文件摘要；普通 v1 与[历史 v1 契约](historical-name-data-contract.md)继续保留，不新增 Backend/OpenAPI、Foundation 或在线翻译接口。许可随站点 /licenses/advanced-names.txt 分发。标题、字段和结果使用常规字重，不重复显示结果标题。
