# 私聊模块

## 目标与范围

Web 端提供低频轮询的一对一私聊。入口位于全局导航和用户主页，不提供用户搜索。支持最多 1000 字纯文本、每条一张 10 MB 以内图片或一个收藏表情，不支持群聊、输入状态、在线状态、搜索、编辑、Web 推送、端到端加密或消息举报。

## 页面与路由

| 路由 | 用途 | 权限 |
|------|------|------|
| `/messages` | 消息中心私聊列表与空会话面板 | 登录 |
| `/messages/[id]` | 会话历史、请求处理、发送、撤回与归档 | 登录，仅参与者 |
| `/messages/new/[userId]` | 从用户主页发送首条消息 | 登录 |
| `/notifications` | 消息中心“通知”页签 | 登录 |

全局导航分别提供“通知”和“私聊”入口：通知显示通知未读数，私聊显示已接受会话未读与待处理请求合计。通知页和私聊页仍保留“通知 / 私聊”页签，名称和徽标与全局导航一致。

`/messages`、`/messages/[id]` 和 `/messages/new/[userId]` 使用 `workspace` 页面骨架：左侧全局导航固定为 72px 图标轨道，不显示文字标签和右侧信息栏，但与浏览页保持相同按钮集合；宽屏不会额外显示通知、私聊、收藏或个人主页按钮。会话列表自身使用可截断文本，不允许把窄栏文字挤成逐字竖排。

## 涉及 API

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/direct-conversations?view=` | 主会话、请求与归档列表 |
| POST | `/direct-conversations` | 向指定用户发送首条消息 |
| GET | `/direct-conversations/unread` | 私聊未读与请求合计 |
| GET | `/direct-conversations/by-user/:userId` | 用户主页入口查询联系状态 |
| GET | `/direct-conversations/:id` | 会话详情 |
| GET | `/direct-conversations/:id/messages` | 历史分页或 `after` 增量轮询 |
| POST | `/direct-conversations/:id/messages` | 发送后续消息 |
| PATCH | `/direct-conversations/:id/request` | 接受或拒绝收到的请求 |
| PATCH | `/direct-conversations/:id/archive` | 归档/恢复本人会话 |
| POST | `/direct-conversations/:id/read` | 标记本人实际看到的消息为已读 |
| DELETE | `/direct-messages/:id` | 十分钟内撤回本人消息 |

响应结构以固定 OpenAPI 和 `src/api/types.ts` 的生成类型为事实源。

## 状态与交互

- 互相关注用户的首条消息直接建立会话；否则首条消息进入“请求”。发起方在对方接受前不能继续发送。
- 首聊页根据关系显示不同提示：互关说明会直接建立私聊；陌生关系说明会发送请求；本人拉黑、被对方拉黑、请求被对方拒绝、本人曾拒绝对方均使用独立文案，避免把不同限制合并成同一个模糊提示。
- 收到的请求与普通会话合并在主私聊列表，并按最后消息时间排序；点开请求后在右侧接受、拒绝或拉黑。陌生请求中的图片和表情默认不发起网络加载，用户点击后才展示。
- 拒绝会删除首条请求消息，原发起方不能重试；原接收方以后仍可主动发起。
- 活动会话先按游标加载历史，此后以最新消息 ID 调用 `after` 做增量轮询；每次合并增量后立即从新消息 ID 继续追平，正常每 10 秒查询一次，回到浏览器前台时立即刷新。另每 60 秒对账最近 50 条，用于更新已加载消息的撤回状态，不把对账窗口中尚未分页加载的旧消息追加到尾部；最终时间线始终按 `createdAt` 正序归一化。会话列表和顶栏合计每 30 秒刷新，归档列表只在用户打开“已归档”文件夹时轮询；页面在后台时均停止轮询。
- 打开会话并展示最新接收消息后提交已读锚点。接口不返回对方 `readAt`，UI 不显示已读回执。
- 自己的消息创建后十分钟内显示“撤回”。待处理首条撤回会取消请求；普通消息保留撤回占位。
- 归档仅影响本人；任一方发送新消息会自动解除双方归档。主列表不再使用“会话 / 请求 / 已归档”三页签：存在归档会话时才在列表顶端显示同层级的“已归档”文件夹卡片，点击后左栏切换为归档私聊列表；没有归档时不显示该入口。归档/恢复成功只更新图标与列表状态，失败显示错误 Toast。
- 拉黑或对方注销后保留历史但隐藏输入框。由于会话只暴露双向合并的阻止状态，解除本人黑名单仍从账号安全页操作，避免把“被对方拉黑”误显示为可解除。拉黑成功由只读状态反馈，不重复显示成功 Toast。

## 内容与图片安全

- 正文使用 React 文本节点和 `whitespace-pre-wrap` 渲染，不使用 `dangerouslySetInnerHTML`，不解析 Markdown。
- 普通消息正文使用 Noto Sans SC Variable、`16px / 28px`，保留系统和浏览器缩放；链接继承同一字号。气泡最大宽度为会话面板 72%，但短消息由正文宽度决定。
- 仅把 `http/https` 片段转换为新窗口链接，并设置 `noopener noreferrer nofollow`。
- 图片复用媒体上传管线。发送前显示“公开 URL、不要发送敏感内容”的提示；发送期间在输入区内显示准备、真实已传/总字节、百分比和媒体处理状态，并允许取消直传；预览对象 URL 在替换、清空和卸载时释放。
- 消息响应的 `media` 始终显式返回 `url`、`thumbnailUrl`、`mediumUrl`（派生图未就绪时后二者为 `null`）。普通静态图优先显示 `mediumUrl`，GIF 使用 `url` 原图；Web/Flutter 均不得通过文件名拼接派生图地址。
- GIF 可在选择预览和消息气泡中播放。气泡直接请求 GIF 原图，不替换为只含首帧的 `_md.webp`；陌生消息请求仍需用户点击后才加载。
- 编辑器内可打开最近/收藏表情面板；点选后立即发送独立 `stickerAssetId`，不清空已输入文字或待发图片。纯表情气泡最大 128px、无背景；静态表情优先加载缩略图，动图加载规范化动画资产。普通消息图片和表情都可悬停或聚焦后收藏。
- 每次发送生成 UUID v4 `clientRequestId`；请求失败且输入未变化时复用同一键，避免响应丢失造成重复消息。用户修改正文或图片后才生成新键。
- 后续消息发送时先写入带“发送中”状态的乐观缓存并立即清空输入框、滚动到最新消息；成功后原位替换为服务端消息，失败时移除乐观消息、恢复原输入并保留同一幂等键供重试。
- 会话历史使用 TanStack Virtual 按可见范围渲染动态高度消息，并由虚拟列表直接更新滚动项位置，避免每个滚动事件都触发整面板渲染；消息 ID 和尺寸估算回调在数据不变时保持稳定，消息气泡跳过无变化重绘。首次进入定位到底部；位于底部时自动跟随新增消息，本人乐观消息始终平滑跟随；向上阅读时保留当前位置并显示“回到最新消息”，点击后主动刷新并一次定位到底部，向前分页通过稳定消息 ID 保持视口锚点。
- 文本气泡与时间行分别自适应宽度，短文本不会被较宽的时间标签撑开；气泡仍以会话面板 72% 为最大宽度。
- 消息时间不再附着于每条气泡：首条可见消息显示居中时间节点，之后仅在相邻消息间隔达到 5 分钟时追加节点；当天显示时分，昨天、同年更早和跨年消息逐级补充日期。

## 组件与缓存

| 文件 | 职责 |
|------|------|
| `message-center-tabs.tsx` | 私聊/通知页签与分项徽标 |
| `direct-conversation-list.tsx` | 普通会话与请求合并、条件归档文件夹、归档子列表及各自游标加载 |
| `direct-conversation-panel.tsx` | 请求、历史、已读、归档、拉黑、发送和撤回编排 |
| `direct-message-composer.tsx` | 1000 字纯文本、单图上传、表情面板和公开 URL 提示 |
| `direct-message-bubble.tsx` | 安全文本链接、GIF/表情播放、快速收藏、陌生图片延迟展示和撤回占位 |
| `direct-conversation-entry-copy.ts` | 首聊页按互关、拉黑与拒绝关系生成准确提示 |
| `use-direct-conversations.ts` | 列表、详情、联系状态、未读查询 |
| `use-direct-messages.ts` | 历史分页、`after` 增量同步、60 秒撤回对账与按 ID 合并去重 |
| `use-direct-message-actions.ts` | 发起、发送、请求处理、归档、已读和撤回 mutation |

全部私聊 Query Key 包含当前 `userId`，登录切换时不会串号。发送时先把乐观消息并入历史缓存，成功后原位替换并失效会话、列表和未读计数，失败只回滚对应乐观消息。

## 验收

- 全局导航分别提供通知和私聊入口及各自徽标
- 私聊/通知页签名称和徽标与全局导航一致
- 私聊工作区固定使用 72px 图标导航，窄栏不渲染文字标签
- 普通消息正文使用 16px / 28px，在默认缩放下清晰可读
- 用户主页私聊入口与首条消息
- 消息请求接受、拒绝和陌生图片点击加载
- 纯文本、单图、收藏表情、未读、十分钟撤回、归档与拉黑只读历史
- 单图上传持续展示真实字节和百分比，可取消后保留待发内容
- GIF 动图预览与播放，以及首聊关系状态差异化提示
- 请求并入主列表；归档以按需显示的文件夹卡片进入独立列表
- 10 秒活动会话增量轮询、60 秒撤回对账和按可见性启停的 30 秒列表/徽标轮询
- 发送消息乐观上屏、失败回滚、自动滚底与短文本气泡自适应
- 长会话虚拟渲染、向前分页锚点保持与离底返回入口
- 类 QQ 的五分钟会话时间线与渐进式日期文案
- OpenAPI 生成类型、hooks 与核心组件测试
