# PC 管理后台、举报与申诉

## 产品边界

管理后台只提供 PC Web 界面，不进入公共导航并设置 `noindex`。管理员身份来自一个已注册的温油账号，但后台使用独立 HttpOnly Cookie 会话：密码和管理员验证码建立会话，高风险操作再次邮件确认；普通用户 access token 不能进入管理 API。公开前台中的管理员权力入口是另一条受限通道：服务端直接以普通 Bearer 登录态实时校验管理员角色，不要求站务会话。

移动端不提供后台界面。用户举报、决定查询和申诉使用平台无关的普通 Bearer JSON API；PC 站务会话只用于管理 API。

后台名称为“温油站管理后台”。导航依次为总览、用户管理、内容管理、运营管理、举报与申诉、系统管理；所有分组默认展开，管理员账号仅超级管理员可见。保留所有既有入口地址。

侧栏 208px、页头 48px、工作区内边距 16px；表格正文 14px，常规行约 40px、双行约 56px，紧凑控件不小于 32px。表格占满工作区，宽表在自身容器滚动，操作列固定在右侧，页面不横向滚动。后台只消费现有 Foundation Token，不改变公共前台的视觉。

每页一个主标题，禁止用途复述、冗余副标题和开发说明，也不迁移为常驻 Tooltip。仅保留字段、状态、错误及必要操作后果。用户与内容使用独立详情页，返回恢复列表筛选、已访问游标及滚动位置；短表单、举报处理和申诉复核继续用弹窗。

## 列表筛选与分页

- 建案、举报、申诉及处理、处置决定、隐藏、审计、通知排期、管理员会话与邀请到期时间直接显示用户本地 `yyyy-MM-dd HH:mm`；普通用户加入时间沿用内容时间模式。预约和有效期输入保留时分精度。

- 案件、申诉、用户、内容、审计和通知活动使用后端不透明游标；默认每页 20 条，内容支持切换 50 条；Web 只保存访问过的上一页游标，不解析或改写游标。改变任一筛选条件会回到第一页。
- 案件可组合状态、目标类型和举报原因；申诉可组合状态、目标类型和原处置；用户可组合关键词、精确用户编号、角色和账号状态；内容可按四种类型、关键词或编号、作者、状态和北京时间日期筛选，主题帖额外支持分类与标签；审计可组合动作、目标类型、目标 ID 与北京时间日期区间；通知活动可组合关键词、发送状态和跳转目标。
- 管理员账号、待接受邀请、主题分类和平台标签是单次返回的小型配置登记册，使用 TanStack Table 的客户端分页与业务筛选，避免为低基数配置另建平行分页协议。
- 所有列表使用带固定列名和独立操作列的传统数据表格，状态、主体、时间和数量不藏进卡片；筛选区只使用高对比中性色，品牌色仅标记当前选择，业务状态再使用对应状态色。
- 所有列表始终显示分页器、当前页条数、明确的上一页/下一页禁用状态，以及可一次清除组合条件的筛选带；搜索框不作为唯一筛选能力。
- 面向站务人员的字段名、状态和操作说明使用自然中文；稳定标识、目标编号等确需保留的技术值必须配中文字段名。
- 列表筛选使用 `nuqs` 保存为类型化 URL 查询参数：刷新或分享链接会恢复同一筛选，非法枚举会安全回落。管理员账号、邀请、分类和标签的客户端页码也写入 URL；后端不透明游标仍只保存在当前 Web 会话的访问栈中，不暴露或改写跨端游标。
- 总览默认近 30 天，可选近 7 天和自定义北京时间日期区间。首屏显示用户总数、活跃用户、新增用户、内容产出；趋势可切换用户活动与四类内容发布。举报与申诉为紧凑待办入口；运行状态独立加载，失败不阻塞统计。

## 客户端边界

登录提供账号、密码、邮箱验证码及默认关闭的“记住此设备（7天）”。选择只保留在本次表单内并随验证码提交；密码进入验证码阶段即清空，密码和验证码均不持久化。未勾选保留闲置 30 分钟、最长 8 小时的短会话；勾选为固定 7 天、不滚动且不按闲置续期，仍使用独立 HttpOnly Cookie、CSRF 和原高风险验证。

后台共享 `checking / authenticated / unauthenticated / unavailable` 状态，只有管理接口 HTTP 401 且错误码 `40117 / 40118` 终止会话；业务权限、CSRF、提权、限流、服务异常和网络失败不按整体退出处理。旧后台缓存与错误同时存在时，终态立即隐藏后台，清空 CSRF、取消请求并移除管理查询和导航访问栈；会话代次检查覆盖响应正文解析，旧查询及旧登录结果不能覆盖新身份。

已有会话复核中或暂时不可用时保留表单并阻止管理操作，失败可重试。重新进入后台、回到前台及断网恢复会核验会话，已返回的 `expiresAt` 只安排一次绝对到期核验；不新增定时保活。原总览与服务健康的 60 秒轮询继续保留，总览管理请求仍计入后端的请求活跃规则。

跨标签只广播无凭据随机事件，接收方重新核验 Cookie；不广播身份、CSRF、密码或验证码。后台 QueryClient 与社区身份隔离，社区切换、退出及迟到 401 不重挂后台或带走后台路由；后台不执行每日签到。登录回跳只接受本站管理工作区路径并保留筛选，主动退出不保存回跳；过期不保存未提交表单。

- 所有 API 经过共享 `apiClient`；`src/api/types.ts` 只由固定 OpenAPI 生成。
- 管理 CSRF token 只保存在内存中，由 `/admin/auth/session` 返回；仅对管理写请求附加 `X-CSRF-Token`。
- 普通用户 access token 和管理员 Cookie 会话互不替代。接受邀请后清除普通 Web 本地会话，再跳转站务登录。
- 普通前台登录态为 `ADMIN / SUPER_ADMIN` 时，公开主题帖、楼层/回复、动态和动态评论显示“站务隐藏”入口；提交直接调用 `/moderation/content/:type/:id/hide`，使用当前普通 Bearer 登录态，不核验独立站务 Cookie、CSRF 或邮件 step-up。服务端从数据库实时校验角色，普通用户即使自行构造请求也会被拒绝。
- 内容列表与详情只消费后端已授权的公开发布内容和管理员隐藏项，排除私密、草稿、作者删除及其子项。主题帖和楼层详情复用安全 Markdown，动态与评论保留纯文本语义；附件使用后端授权的媒体展示描述，不另行调用普通用户媒体接口。父级隐藏时显示受限状态，恢复限制以服务端返回值为准。
- 保留按前台链接或裸编号的直接隐藏、恢复入口，复用原解析与写接口，包括旧入口可定位但不在新列表展示的合法目标；不以读取失败自动扩大检索权限。
- 用户详情显示资料、等级、注册时间、最近活跃日期及四类可管理内容数量；没有活跃记录显示“暂无记录”。关联入口带入作者与类型筛选，统计和列表共用服务端可见性规则。暂停、封禁、解除集中于账号状态弹窗。
- 主题帖可单项整理分类与标签；提交当前版本及理由，最多 5 个已注册标签。新选择必须启用，已有停用项允许保留或移除。版本冲突保留输入并提示重新读取，新版本分类和标签仅在冲突核对区显示；成功后刷新后台、公开详情、列表、搜索及相关缓存。
- 站务列表、详情、决定和写入通过 `src/api/hooks/use-admin.ts` 统一缓存及失效，不在组件内直接 `fetch`。
- 分类的 `slug` 是主题帖外键和跨端接口使用的稳定标识，创建后不可修改；名称、描述、排序和启停状态由站务台编辑，分类 API 不定义颜色字段。分类写入成功后同时失效站务列表与公开分类缓存，不需要等待五分钟缓存过期。
- 举报表单显式携带 `targetType/targetId`；私聊举报由后端再次确认当前用户是接收者。

站务登录、邀请接受、工作区、内部区块及操作弹窗统一使用系统字体 body，标题为 600 字重；字号、行高、布局及数字的 utility 字体保持现状。

## 验证

`pnpm check:full` 覆盖 lint、TypeScript、生成契约、架构/设计约束、单元测试与覆盖率、文档事实检查、生产构建和隔离 standalone 浏览器回归。后台接口变更必须先生成后端 OpenAPI，再同步前端契约；不手改生成类型。 所有浏览器用例继承统一隔离 fixture；登录和写入前验证本轮 `runId`、资源归属与候选实际代理，结束后按登记清理，清理失败不能算通过。隔离 `.next-e2e` 构建不用于部署，线上仅执行匿名只读烟雾。

新增回归覆盖身份切换、游标筛选 A→B→A、详情返回位置、列表加载/空结果/失败、服务健康局部失败、分类标签冲突输入保留与重复提交。`e2e/admin-console.spec.ts` 检查 1024/1366/1920px 亮暗布局、1366×768 首屏 12 条单行内容、固定操作列、键盘及 200% 缩放；`e2e/station-layout.spec.ts` 保留登录、通知、用户状态和举报处理流程。视觉基线必须先审阅实际截图再更新。

分类创建与编辑、治理决定、内容处置、账号状态和运行设置复用 `FormField`，字段错误关联实际输入或选择控件；保留各自 RHF/Zod 校验、权限和接口错误。提交按钮复用 pending 状态，同一表单的未决写入通过同步锁防重；处置弹窗提交期间禁止关闭，失败保留输入供重试。

后台文本字段按后端DTO的Unicode码点限制校验；处置理由与公开说明允许至少1个非空字符，仍保留各字段最大长度。详见[能力一致性报告](../verification/capability-consistency.md)。

## 移动端版本说明

运营管理中的“移动端版本”按平台、版本名和构建号维护更新说明。首期面向 Android；后台仅维护说明，确认动作不发包、不调整客户端推荐或强制升级策略。

未登录时直接访问 `/station/mobile-releases`，完成站务登录后回到移动端版本页；该入口的回跳仅接受精确列表路径，未知子路径和相似名称回落到后台首页。

跨端展示语义遵循 [Foundation 更新说明规范](https://github.com/morenk/wenyousite-foundation/blob/d9001265030a52d5255c7cd52dc841833cc7afbb/docs/mobile-releases.md)，不新增 Token 或升级 Foundation 包版本。预览头部始终显示平台、版本名、构建号及内容状态。

- 列表展示平台、版本与构建号、草稿／待发布／已发布状态，以及已发布记录的待修订状态，使用服务端返回的不透明游标翻页。
- 摘要和逐条内容使用纯文本。一行一项，忽略空行并保留顺序；预览直接显示文字，Markdown、HTML 和链接语法不转成富文本或可点击链接。
- 普通管理员可查看版本和编辑未发布草稿；超级管理员确认说明，并负责已发布文案的编辑与确认。按钮权限仅辅助操作，最终由服务端校验。
- 草稿和待发布说明不进入公开历史。已发布说明编辑期间继续展示之前确认的公开快照，修正经超级管理员确认后替换；版本发布由独立发布流程完成。
- 保存与确认期间禁用重复操作。字段错误显示在对应输入框附近，权限拒绝和并发冲突保留输入；冲突时先读取并核对最新记录，再决定保存。修订、确认和公开状态以服务端返回事实为准，不乐观显示成功。
- 说明创建后不会自动补写历史版本，也不从 Git 提交生成文案。

管理浏览器联验使用 Backend `72d3658d32a089fcfabdea30225d87b960033c5b` 的 `--admin-fixtures --mobile-release-fixtures` 入口，提供同一轮随机 ADMIN/SUPER_ADMIN 和已发布／草稿样本。Web runner 传递这些旗标，账号与本地验证码收件箱仅从本轮私有描述读取，先校验 runId、路径、文件权限与真实代理；不向 Next 构建或服务传递账号。失败诊断同时移除普通用户和管理账号凭据。`e2e/mobile-releases.spec.ts` 通过实际站务登录和管理接口验证创建、并发冲突、确认、角色权限、未发布内容不可公开，以及已发布修正确认前后公开快照的变化；截图使用本轮合成数据，遮盖管理账号并标记候选待验收。

`e2e/admin-session.spec.ts` 沿用 typography → isolation fixture，覆盖亮暗登录选择、键盘、安全回跳、独立 Cookie/CSRF 请求、跨标签退出、旧缓存终态隐藏与业务 403 保留后台。跨标签使用同一受控 context；真实写入与会话时限验证只能通过已提交隔离入口进行，不复用手工启动的后端或历史测试凭据。

## 正文字体

`/station/text-fonts` 使用服务端管理查询：名称包含匹配、语言和发布状态（草稿／启用／停用／已撤回）先作用于全部家族，再按新增时间、修改时间、名称或展示顺序排序，每页 20 条。默认最近新增降序；筛选与排序保存在 URL，改变条件回到第一页，游标过期（40931）保留条件重新读取第一页。名称、语言和发布状态采用服务端投影，不从当前版本是否为空猜测撤回状态。最新处理任务状态单独显示，读取错误与空结果分开。

上传页只要求单个 TTF/OTF 文件（最大 64 MiB）、名称和语言。名称预填文件名且可修改，语言默认“未分类”。“上传并处理”依次创建提交、上传二进制、启动处理；上传即确认分发、转换和分片权利，服务端保存确认记录并继续核验字体本身的限制。已有家族上传新版只选择文件，沿用已保存名称与语言。作者、来源、许可、样张文字放在默认折叠的“更多信息”，不作为简化上传的必填项；空样张或纯空格使用契约中的对应语言默认文字：中文／日文为“温油文字 Aa 0123”，英文／未分类为“Wenyou Aa 0123”。已有非空样张与自定义文字保留，不改写历史版本样张或 legacy v1 预览。已填写来源必须是 HTTP(S) URL。源文件及配置快照绑定提交，不接受压缩包、字体集合或远程 URL。

浏览器按管理员及任务保存非凭证恢复信息：提交标识、首次完整创建请求（包括原家族修订）、首次及当前处理请求标识和源文件摘要；文件本身不持久化。刷新或结果未知先 GET 原提交，确认不存在才原样重放首次创建请求。已绑定任务不重传文件，未上传时要求重新选择原文件；明确重试失败任务才换处理请求标识。详情通过任务的提交标识继续新流程任务，不依赖当前列表页、同名猜测或仅依赖浏览器存储；旧任务保留旧接口与授权检查。新建上传页处理完成后直接显示真实样张，并提供进入详情手动发布的入口；已有家族在详情的版本区域预览，不重复显示样张，不自动发布。

上传进度使用实际已传字节；处理阶段只显示排队／处理中。所有写入防重复点击。传输连续 120 秒没有新增进度即中止，上传到 100% 后等待响应也有界；持续推进的慢传不受短绝对总时长限制。创建、恢复查询和启动处理的 JSON 请求也有 120 秒等待上限，避免恢复阶段无限等待。超时、连接中断及非 JSON 网关错误保留输入和恢复键，先查询结果，不自动重发写入；管理会话变化会中止上传。Next 重写代理缓冲上限为 64 MiB，上游套接字空闲超时为 120 秒；公网 API 由 Caddy 直接转发，网关和 Backend 必须分别允许完整 67108864 字节请求体。

“调整展示顺序”是独立模式，先分页读取全部可选字体并校验目录／列表修订和完整性，再按当前发布语言分组。置顶、上移、下移及 Alt+Home／Alt+↑／Alt+↓ 只修改本地草稿；保存时一次提交全部改变语言的完整家族列表及家族／目录修订。冲突要求读取最新顺序后重排，未知结果先读取完整集合确认，确定失败可重试，不逐项补偿或自动覆盖。排序不会重建字体或改变历史版本 ID、缓存资源和正文；成功后刷新管理列表、审计及 v2 公开目录。v2 选择器遵循服务端顺序，不按最近使用、名称或选中项重排；同一组版本 ID 的目录修订变化也更新当前会话。

所有操作使用现有后台 Cookie 与 CSRF；撤回复用 `HighRiskGate` 并要求理由。修改携带家族修订，发布、启停与撤回同时核验目录修订；冲突时保留输入并要求读取最新状态。版本列表不会改变历史正文引用的不可变 ID，回滚只切换当前可选版本。后台样张在待发布、已发布及停用状态始终经过管理员认证网关，不读写公共磁盘缓存。样张按可见性加载，点击任务行“预览”会将版本与样张区域滚入视口（包括已选版本），后台处理状态更新不抢滚动；暂时失败可自动或手动重试，当前选中版本的实际图片成功显示后才允许发布，切换版本重新等待该版本样张，预览读取失败时也阻止发布，重试成功后恢复；不为列表下载完整字体。撤回不可恢复，历史源码保留；新版客户端停止下载和呈现该字体，旧版客户端可能不受影响，确认弹窗明确这一边界。

上传面板与任务详情共用固定失败文案：处理环境暂不可用、文件无效、格式不支持、授权不完整或资源限制等。字体禁止嵌入、禁止分片、仅允许位图嵌入的具体限制优先显示；未知类别使用通用提示，不回显原始诊断。失败后仍可手动使用已上传文件重试，不自动重传或重试。

动态字体的配置、上传、处理、就绪、发布、启停、撤回与历史导入均在审计页以中文动作显示，支持 `TEXT_FONT` 目标和对应动作筛选。

窄视口下管理导航默认折叠，点击左上角菜单展开，选择页面或按 Escape 收起；宽视口保留固定侧栏。正文字体配置在窄视口单列显示，语言选择显示中文标签，表格仍在自身容器内横向滚动。
