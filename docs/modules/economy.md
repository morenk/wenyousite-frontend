# 用户等级与温油

## 用户旅程

已登录会话初始化后，`DailyCheckInBootstrap` 自动调用 `POST /wallet/check-in`。服务端按北京时间自然日幂等处理；仅当 `claimedNow=true` 时显示“今日签到获得 1～3 升温油”的轻提示，不展示连续签到或每日任务清单。

全局导航栏持续显示当前温油余额并链接到 `/wallet`。钱包页只允许本人访问，展示余额和 Cursor 分页收支流水。签到记录显示实际领取数；支出显示投入总额；收入显示投入者、对方投入总额以及扣除平台份额后的实际到账。公众无法查看捐赠人或他人的流水。

主题帖详情、动态详情和他人用户主页提供无常驻边框或填充的“加油”入口，并统一使用加油枪图标。弹窗只显示接收者、升数和确认操作；金额必须是不小于 2 的十进制整数升，非法输入时再显示约束，不向投入者展开平台分成或接收者到账金额。组件为同一金额的失败重试保留 UUID `clientRequestId`，金额变化或成功后才生成新的用户操作 ID。成功提示只确认本次加油升数，并同步刷新顶栏钱包、私密流水与对应公开统计；接收者仍可在自己的钱包流水中核对实际到账。

## 展示规则

- 主题帖列表和详情公开 `tipTotal`。
- 动态卡片和详情公开 `tipTotal`，投入者名单仅存在于本人钱包流水中。
- 用户主页公开 `receivedTipTotal` 与 `receivedTipCount`，显示的是用户投入总额，不是扣费后的实际到账。
- 用户摘要与内容作者显示 `Lv.1`～`Lv.9` 数字徽章。
- `/me` 显示本人精确经验、当前等级区间和下一级门槛；Lv.9 显示已达最高等级但经验继续累计。
- 金额保持 OpenAPI 的十进制字符串语义，格式化时使用 `BigInt`，不经过会丢精度的浮点数。

## API 与状态

| Method | Path | 用途 |
|--------|------|------|
| GET | `/wallet` | 本人余额与累计收款统计 |
| POST | `/wallet/check-in` | 北京时间每日幂等签到 |
| GET | `/wallet/transactions` | 本人私密流水 |
| POST | `/threads/:id/tips` | 向主题帖楼主投入温油 |
| POST | `/moments/:id/tips` | 向动态作者投入温油 |
| POST | `/users/:id/tips` | 直接向用户投入温油 |

所有请求通过 `src/api/hooks/use-economy.ts`。缓存键由 `queryKeys.wallet` 统一生成并含当前用户 ID；登录身份切换仍会重建 QueryClient，避免余额和流水跨账号复用。自动签到、投入成功会更新余额快照并失效关联流水与公开对象查询。
