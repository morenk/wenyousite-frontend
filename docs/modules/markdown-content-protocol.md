# Markdown 正文内容协议

Web 与 Flutter 共用数据库中的 Markdown 字符串，不修改既有字段或数据表。

## 空段落

- 编辑器将顶层空段落写成独占一行 `<br />`；`<br>`、`<br/>`、`<br >` 仅作为历史兼容输入，写入时规范化为 `<br />`。
- 仅转换代码块外、正文顶层的独占标记。代码块中的 `<br />` 是代码文本；列表、引用等嵌套结构不做特殊提升。
- 客户端渲染时把协议标记转换为安全的换行节点，禁止执行任意 HTML。前端摘要、通知和搜索预览会移除空段落标记并折叠连续空白。
- 不设空行数量上限，仅受现有 Markdown 总长度限制；首部、中间、尾部空段落均按顺序保留。

## 发布校验

纯空白、仅空段落或仅一条分隔线（`---`）不可发布；图片、代码块、列表和普通文本（包括纯数字正文，如 `123`、`1.00`）均属于有效内容。空图片/空链接以及不可见零宽字符不构成正文。草稿仍可保存为空。

## 高度折叠

楼层、子贴正文和回复使用同一渲染组件：实际高度超过当前视口 `1.2` 倍时默认限制为 `80vh`，显示“展开全文”；展开或收起只在当前组件生命周期有效，窗口尺寸变化会重新测量。

Flutter 端应遵循同一存储与校验规则，并将独占 `<br />` 渲染为空段落而不是 HTML。
