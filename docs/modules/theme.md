# 外观主题

## 1. 可观察行为

- 页面提供“跟随系统、亮色、黑夜”三种偏好，默认跟随系统；实际绘制模式始终解析为亮色或黑夜。
- 显式偏好以 `wenyousite-theme` 保存到当前浏览器的 `localStorage`，不包含凭证，不写入用户资料，也不通过后端同步。其他同源标签页修改该键时，已打开页面同步更新。
- 选择“跟随系统”后，`prefers-color-scheme` 变化会实时更新页面；显式亮色或黑夜不会被系统变化覆盖。
- 根布局在 React hydration 前写入 `data-theme`、`data-theme-preference`、`color-scheme` 与浏览器主题色，刷新和路由切换不先闪出另一套主题。存储不可读或值非法时安全回到跟随系统。
- 主题切换不改变布局、信息密度、内容顺序或图片裁切，也不显示成功 Toast。正文图片、头像、封面和外部内容保持原始像素，不套用全局反色或亮度滤镜。

## 2. 入口与无障碍

- 社区页和工作区在左侧全局导航底部显示“外观”；认证页与站务壳在右上角保留紧凑入口。
- 弹层使用原生单选组语义，三个选项带 Foundation 外观图标、可见选中标记与键盘方向键行为；触发器的可访问名称包含当前偏好。
- 切换结果同步到原生 `color-scheme`、主题色、Sonner、Milkdown Crepe、普通浮层与图片查看器。焦点环、选中标记和状态同时保留形状或文字线索，不只依赖颜色。

## 3. 设计映射

- Foundation `v6.6.1` 的 Web Token 是亮色与温暖墨紫黑夜模式的唯一色板来源。页面代码不复制色值。
- `actionPrimary` 用于主要行动，`primary` 用于柔和容器与低强调选中面，`brandStrong` 用于导航线路、进度、未读点和定位边界。
- 页面画布使用 `background`，卡片与浮层使用 `card` / `popover`；黑夜模式不使用纯黑、霓虹发光、玻璃拟态或环境渐变制造层级。
- 标题品牌图在黑夜使用同一资源透明轮廓的 `brandStrong` 蒙版，保持几何和装饰语义不变。

## 4. 回归边界

- 单元与组件测试覆盖偏好解析、非法存储回退、本地写入、系统媒体变化、跨标签页事件和单选菜单。
- Playwright 覆盖首屏解析、刷新恢复、三种偏好、系统变化、键盘操作、浏览器主题色以及亮色/黑夜截图和自动无障碍扫描。
