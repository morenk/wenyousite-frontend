# 构造封面媒体

这些文件使用固定随机种子 20260911 和 Pillow 构造，不含真实用户素材。motion 为 480×270、12 帧、每帧 100 ms、无限循环的渐变纹理/移动方块，同一帧序列分别编码 GIF 与质量 70 的动画 WebP；poster 是第一帧。clock 为 80×80 红、绿、蓝三帧，各 1500 ms，重复一次后结束（总共两轮；GIF loop=1 表示追加一轮，WebP loop=2 表示总共两轮），用于真实截图像素验证首帧/重入/有限循环。WebP clock 为无损编码。

压缩率仅说明该构造素材，不能代表论坛真实 GIF。性能样本必须记录源策略、构建、viewport、数量及冷热状态。HTTP 请求字节包括传输数据，rAF 间隔不等于动画帧率，也不报告未实际测量的全部解码内存。
